# Nivora Market

Nivora Market is a full-stack e-commerce marketplace designed for customers to browse, search, and purchase products across categories such as electronics, mobiles, computers, electrical products, tools, plumbing, and more.

The project includes both customer and admin functionality, with product management, authentication, cart, wishlist, checkout, order management, and a simulated payment system.

## Features

### Customer

- User registration and login
- Product browsing and search
- Category-based product filtering
- Product details
- Shopping cart
- Wishlist
- Checkout
- Simulated payment
- Order confirmation
- Order history
- Order tracking
- Profile and address management
- Notifications

### Admin

- Separate admin login
- Admin registration
- Dashboard
- Product management
- Category management
- Customer management
- Order management
- Inventory management
- Notifications
- Reports

## Technology Stack

- React
- JavaScript
- Tailwind CSS
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- Cloudinary
- Vercel

## Project Structure

The project contains a React frontend and a Node.js/Express backend.

The frontend handles the user interface and customer interactions, while the backend manages authentication, products, orders, users, and database operations.

Product images are stored using Cloudinary, while product information and other application data are stored in MongoDB.
